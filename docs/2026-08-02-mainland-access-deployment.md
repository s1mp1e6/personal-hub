# 国内访问部署手册（2026-08-02）

想直接照着点，先看《现在就能上线的实操方案（子域名 + 国内替代）》（同目录 `2026-08-02-do-it-now-step-by-step.md`）；本文档负责整体判断和长期备案路线。

目标：让 Personal Hub 在中国大陆的手机/电脑能稳定打开，并把“短码信令”也逐步迁到国内链路。本文档按“今天就能做”和“长期稳定”两档给出步骤。

## 结论速览

1. 只搞定域名不够。还差两件事：静态站点托管（GitHub Pages 只是其中一种）和短码信令中转（现在跑在 Cloudflare Worker 上）。
2. 不需要买传统 VPS。EdgeOne Pages 本身是免费静态托管，能替代 GitHub Pages；也不需要自己配 Nginx。
3. 但目前没有“合法且免费、还保证国内直连稳定”的路径：
   - 已实测工信部域名接口：`zal.best` 所属的 `.BEST` 不在可备案英文顶级域名单里，永远无法完成 ICP 备案。
   - EdgeOne Makers 官方文档：只有“全球可用区（不含中国大陆）”不要求备案，但国内网络访问走境外节点，属于“能开但看运气”。
   - 要拿到大陆节点稳定访问，必须用可备案域名（`.cn`/`.com` 等）+ ICP 备案；备案本身免费，但腾讯云要求账号下先有“备案资源”。最便宜的已核实方案是云函数备案资源包：5000 万次调用 + 40 万 GBs，60 个月，110 元（腾讯云官方文档售价），比轻量服务器（约 100-150 元/年）更省。
4. 所以推荐路线分两步：
   - 第一步（今天，免费）：EdgeOne Makers 不含大陆可用区 + 绑定 `hub.zal.best`，先把访问从 GitHub Pages 换成腾讯系链路。
   - 第二步（要稳定）：新注册一个 `.cn` 或 `.com` 域名并完成备案（备案资源最低 110 元/60 个月），再切到 EdgeOne 含大陆可用区，最后把信令中转也迁到 EdgeOne Functions 或腾讯云函数。

## 正面回答：国内直连真的做不到吗？

- 严格意义上，做不到“不备案还稳定直连”。大陆 CDN/服务器节点必须绑定已备案域名，这是监管要求，不是技术限制；没有备案，任何免费托管（GitHub Pages、Cloudflare Pages、Vercel、Netlify）都只能用境外节点，能不能打开、快不快全看网络运气。
- “直连”和“能打开”是两回事。Personal Hub 没有服务端登录，你感觉“登录界面难”，实际是首页本身在境外节点、国内 TLS 握手经常超时；这不是项目代码问题。
- 市面上所谓“免备案国内加速”大多是灰产 CDN 或套用他人备案域名，域名随时可能被封，还可能夹带数据风险；不建议碰。
- 唯一合法稳定路径就是：可备案域名 + ICP 备案 + 大陆节点。成本可以压得很低：新域名首年几十元 + 云函数备案资源包 110 元/60 个月 + 备案免费。
- 想“今天花小钱明显改善”的中间方案是香港轻量服务器（活动价常见约 99-150 元/年，选 CN2 优化线路）。它是境外服务器，不是大陆直连，但线路通常比 GitHub Pages 好很多；这是付费方案，也不承诺 100% 稳定。

## 第一步：今天就能做（约 10-30 分钟，免费）

### 1. 注册/登录腾讯云并实名
1. 打开腾讯云官网注册账号。
2. 完成个人实名认证（微信/QQ 均可，通常几分钟内通过）。
3. 打开 EdgeOne Makers：`https://pages.edgeone.ai`，用同一个腾讯云账号登录。

### 2. 导入 GitHub 仓库并部署
1. 在 EdgeOne Makers 控制台点“新建项目”，选择导入 GitHub 仓库。
2. 授权 GitHub 后选择 `10-Personal-Hub`（或 GitHub 上的仓库名）。
3. 项目设置里：
   - 根目录/输出目录填 `site`
   - 构建命令留空（项目是纯静态文件，不需要构建）
   - 加速区域选“全球可用区（不含中国大陆）”
4. 点“开始部署”。先在 EdgeOne 控制台预览，或从非大陆网络打开系统分配的项目域名，确认页面能正常加载，首页二维码、主题、本地数据都正常。
   > 注意：加速区域为“全球可用区（不含中国大陆）”时，官方文档说明系统分配的项目域名从大陆网络访问可能返回 401，所以大陆手机实测要等绑定 `hub.zal.best` 自定义域名后再做。

### 3. 绑定 `hub.zal.best`
1. 在项目“域名管理”里点“添加自定义域名”，输入 `hub.zal.best`。
2. EdgeOne 会给你一个 CNAME 目标地址（形如 `xxx.edgeone.app` 或类似），并提示验证方式。
3. 去 Cloudflare 添加 DNS 记录（实测 `zal.best` 的 NS 已是 Cloudflare，不在 Spaceship 加）：
   - 打开 `https://dash.cloudflare.com` → 登录 → 点 `zal.best` → 左侧“DNS” → “记录 / Records”
   - 验证 TXT 按 EdgeOne 弹窗要求添加（类型 `TXT`，名称和内容照抄）
   - CNAME：类型 `CNAME`，名称 `hub`，目标填 EdgeOne 给的 CNAME 地址，代理状态选“仅 DNS / DNS only”
   - TTL: 自动即可
   - 保存后回 EdgeOne 点“验证”，等状态变为“CNAME 已生效”
4. 回到 EdgeOne 完成验证并等待生效。DNS 最长可能 48 小时，通常几分钟到几小时。
5. 检查 HTTPS：进入“域名管理 → HTTPS 配置”，如果平台没有自动配置证书，选择“EdgeOne 自动完成免费证书申请、部署以及续签”，等证书状态变为已生效（通常几分钟）。
6. 生效后用手机流量（不是 Wi-Fi）和家里宽带分别打开 `https://hub.zal.best` 验证。
7. 注意：不要动 `zal.best` 根域的 A 记录，避免影响另一个项目。

### 4. 验证和测试信令
- 打开同步界面看“连接耗时/诊断”面板，确认各阶段时间。
- 想临时换信令地址测试时，用 `https://hub.zal.best/?relay=https://...` 打开页面即可。
- 由于 EdgeOne 不含大陆可用区，国内访问仍可能慢或偶尔失败；这一步的价值是先把主站从 GitHub Pages 迁移出来，并拿到 HTTPS 和可控域名。

## 第二步：要稳定直连（ICP 备案，约 7-20 个工作日）

### 为什么必须换域名
`.BEST` 不能备案（本会话已通过工信部域名接口实测确认），所以：
- 不迁移域名：永远只能用“不含大陆”区域，无法获得稳定大陆节点。
- 建议在腾讯云新注册一个 `.cn` 或 `.com` 域名（首年一般几十元），专门给 Personal Hub 用。

### 1. 注册可备案域名并实名
1. 在腾讯云域名注册里搜一个没人用的 `.cn` 或 `.com` 域名（例如 `personhub.cn` 这类，先查是否被注册）。
2. 完成域名实名认证（约 1 个工作日）。

### 2. 购买备案资源（最省：110 元/60 个月）
备案本身免费，但腾讯云要求账号下有满足条件的云资源。按花费从低到高：
- 云函数备案资源包（推荐，最便宜）：腾讯云官方备案文档写明，Serverless 方式备案需购买“云函数 5000 万次调用次数包 + 40 万 GBs 资源用量包”，售价 110 元，时长 60 个月。购买入口在云函数（SCF）控制台的“资源包”页，名称即“备案资源包”。这个包后面跑信令/云函数也能用，不算浪费。
- 轻量应用服务器（Lighthouse）：包年包月购买时长不少于 3 个月，且备案期间剩余有效期不少于 1 个月，常见活动价约 100-150 元/年。
- CVM 云服务器：规则与轻量类似，价格通常更高。

不需要把 Personal Hub 跑在这个服务器/资源包上；它只是备案资源，静态站仍然由 EdgeOne Pages 免费托管。
注意：EdgeOne Makers 是否提供“不买资源也能备案”的独立通道，官方文档没有明确说明；不要依赖它，直接买云函数备案资源包最稳。

### 3. 提交 ICP 备案
1. 打开腾讯云 ICP 备案小程序/控制台，按引导填写主体信息（个人姓名、身份证、手机号等）。
2. 填写网站信息，服务内容选个人网站/技术交流类。
3. 腾讯云审核后提交到管局，等待 7-20 个工作日（各省不同，会短信核验）。
4. 备案成功后拿到备案号。

### 4. 切换到大陆可用区
1. 在 EdgeOne Makers 项目设置里把加速区域改成“中国大陆可用区”或“全球可用区（含中国大陆）”。
2. 添加新域名的自定义域名（如 `app.personhub.cn`）。
3. 到域名注册商的 DNS 控制台添加 CNAME，指向 EdgeOne 给的地址。
4. 部署域名等待生效，用手机流量复测。

### 5. 迁移短码信令（后续再做）
当前 Cloudflare Worker 在中转短码时，国内访问也受境外链路影响。稳定方案：
1. 把 `signaling/` 的 Worker 逻辑迁到 EdgeOne Functions（或腾讯云函数 + WebSocket/轮询接口）。
2. 部署后拿到新信令 URL，改 `site/index.html` 的 `shortRelayUrl()`，提交并重新部署 EdgeOne Pages。
3. 用诊断面板确认“信令耗时”明显下降，再考虑停用 Cloudflare Worker。
4. 如果暂时不迁移，可以在第二台设备测试时用 `?relay=` 临时切换，不影响主站访问。

## 常见疑问

1. GitHub Pages、Cloudflare Pages、Vercel、Netlify 免费版为什么不行？
   它们都没有大陆节点，也不承诺国内链路。GitHub Pages 是境外静态托管；Cloudflare 免费版对国内部分网络反而时好时坏；Vercel/Netlify 在国内经常超时甚至打不开。它们适合海外用户，不能替代备案后的国内加速。
2. 必须买 VPS 吗？
   不需要。静态站用 EdgeOne Pages 免费托管；备案资源用 110 元/60 个月的云函数资源包即可，不需要把项目部署到服务器。
3. 为什么首页/“登录界面”都很难打开？
   Personal Hub 没有服务端登录，难打开是因为页面本身在境外节点、国内握手超时。先做第一步迁到 EdgeOne，再考虑备案切大陆区。
4. `zal.best` 能备案吗？
   不能。工信部可备案英文顶级域名单中没有 `.BEST`（本会话已通过 `domain.miit.gov.cn` 接口实测），想稳定必须另注册 `.cn`/`.com`。
5. 备案期间网站还能用吗？
   能。备案期间继续用“不含大陆”区域 + `hub.zal.best`；备案完成后切换区域、换到新域名即可，不需要停机。
6. 以后想多人使用怎么办？
   多人使用只影响信令/资源用量，不影响架构；当前 WebRTC 点对点方案本身适合多人。先把单人多设备跑稳，再开放给更多人。
